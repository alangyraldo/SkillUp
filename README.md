# SkillUp 🎓

### Aprende, enseña y crece con nosotros.

## 📌 Descripción del proyecto

**SkillUp** es una plataforma web orientada a conectar estudiantes con tutores especializados en diferentes áreas del conocimiento, facilitando el acceso a oportunidades de aprendizaje y desarrollo personal y profesional.

La plataforma busca ofrecer una experiencia intuitiva y organizada en la que los usuarios puedan explorar materias, conocer tutores, consultar sus perfiles y encontrar horarios disponibles para agendar tutorías de acuerdo con sus necesidades e intereses.

SkillUp nace con el propósito de promover el aprendizaje continuo, el intercambio de conocimientos y el desarrollo de nuevas habilidades a través de una experiencia digital accesible y dinámica.

## 🎯 Objetivo general

Desarrollar una plataforma web que facilite la conexión entre estudiantes y tutores, permitiendo descubrir oportunidades de aprendizaje, consultar la oferta educativa y gestionar el agendamiento de tutorías de manera sencilla y organizada.

## ✨ Funcionalidades principales

- **Página de inicio:** presenta la plataforma, su propósito y las principales opciones de navegación.
- **Búsqueda de tutores:** permite explorar tutores según las áreas de interés.
- **Catálogo de materias:** facilita la consulta de las diferentes áreas de aprendizaje disponibles.
- **Perfiles de tutores:** ofrece información relevante sobre su experiencia, especialidades y modalidades de enseñanza.
- **Agendamiento de tutorías:** permite seleccionar una materia, un tutor y un horario para programar una sesión.
- **Gestión de tutores:** contempla el registro, la consulta y la actualización de la información de los tutores.
- **Administración de horarios y cupos:** permite gestionar la disponibilidad de los tutores y mantener organizado el proceso de agendamiento.
- **Registro e inicio de sesión:** incorpora las secciones destinadas al acceso y registro de usuarios.
- **Biblioteca de recursos:** ofrece un espacio para organizar y consultar materiales de apoyo al aprendizaje.
- **Contacto e información institucional:** facilita el acceso a información sobre la plataforma y sus canales de comunicación.

## ⚙️ Instalación y ejecución

### Requisitos previos

- Git instalado.
- Un navegador web actualizado.
- Visual Studio Code u otro editor de código.
- Live Server, recomendado para ejecutar la aplicación durante el desarrollo.

### 1. Clonar el repositorio

```bash
git clone https://github.com/alangyraldo/SkillUp.git
```

### 2. Ingresar al directorio

```bash
cd SkillUp
```

### 3. Abrir el proyecto

Abre la carpeta del proyecto en Visual Studio Code y ejecuta el archivo `index.html` utilizando Live Server o el método de ejecución definido por el equipo.

### 4. Explorar la aplicación

Navega por las diferentes secciones para conocer las funcionalidades implementadas y la experiencia de usuario de SkillUp.

## 👥 Metodología de trabajo

El desarrollo de SkillUp se realiza de manera colaborativa, distribuyendo las funcionalidades entre los integrantes del equipo.

Se utiliza Git y GitHub para gestionar el código fuente, trabajar con ramas independientes, integrar contribuciones mediante Pull Requests y mantener organizado el proceso de desarrollo.

La modularización de la aplicación permite que cada integrante trabaje en componentes específicos, favoreciendo la organización, la reutilización y el mantenimiento del código.

## 🚀 Proyección del proyecto

SkillUp busca evolucionar hacia una plataforma integral de aprendizaje que permita fortalecer la experiencia de estudiantes y tutores mediante nuevas funcionalidades, una gestión centralizada de la información y herramientas que faciliten el seguimiento de las tutorías.

Entre sus posibles líneas de evolución se encuentran:

- Fortalecer la gestión de usuarios y los mecanismos de acceso.
- Incorporar una gestión centralizada de tutores, horarios y reservas.
- Mejorar los procesos de búsqueda y selección de tutores.
- Ampliar la biblioteca de recursos educativos.
- Incorporar notificaciones y seguimiento de las tutorías.
- Desarrollar herramientas administrativas para analizar y gestionar la actividad de la plataforma.
